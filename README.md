# Introduction

This is a resource pack which contains: 

Classic texture for new blocks & items in 1.14 ~ 1.20.1. 

Specific texture for Zombified Piglin, which makes it look like Zombie Pigman under 1.16. 

Adjusted several textures for architectures, such as the texture of diorite walls now use quartz blocks instead of diorite.
